# Privacy Policy

Last updated: 2026-09-29

This policy covers a personal, non-commercial application that connects to the WHOOP API using the WHOOP OAuth flow. It is used only by its developer, Lea Nientiedt, for his own WHOOP account.

## Data accessed

With my consent through WHOOP OAuth, the application reads my own WHOOP data: profile, body measurements, recovery, sleep, workouts and cycles.

## Use of data

The data is retrieved on my own computer and used only for my personal analysis through an AI assistant. It is not sold, shared with third parties or used for advertising.

## Storage

OAuth tokens are stored locally on my own computer. The application has no server of its own and does not store data centrally.

## Third parties

Data that I choose to show to an AI assistant during a conversation is processed under that provider's terms.

## Revoking access

I can revoke access at any time in my WHOOP account settings or by deleting the local token file.
